## Sobre o projeto

Este repositório contém o site estático do KT WIRZADE, com apresentação do aplicativo, guias de instalação, segurança, rollback, perguntas frequentes e changelog.

## Desenvolvimento

O site usa Astro. As páginas estão em `src/pages`, os componentes em `src/components` e os arquivos públicos em `public`.

```bash
npm install
npm run dev
npm run build
npm run preview
```

O build gera a saída estática em `dist/`. Para sugerir mudanças na documentação, [abra uma issue](https://github.com/KT-TWEAKS/kt-wirzade-site/issues).
