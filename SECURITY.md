# Política de Segurança

Reporte uma vulnerabilidade de forma privada pela [advisory de segurança](https://github.com/KT-TWEAKS/kt-wirzade-site/security/advisories/new). Evite divulgar detalhes exploráveis em issues públicas.

Inclua impacto, passos de reprodução e uma possível mitigação. A branch `main` é a versão acompanhada.
