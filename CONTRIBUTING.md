# Contribuindo ao site do KT WIRZADE

Abra uma issue antes de mudanças grandes e mantenha cada pull request pequeno, acessível e com objetivo claro.

## Antes de enviar

1. Execute `npm ci` e `npm run build`.
2. Preserve o suporte a `prefers-reduced-motion`, navegação por teclado e contraste.
3. Inclua capturas para mudanças de interface e não invente capacidades do aplicativo.

Ao contribuir, você concorda com o [Código de Conduta](CODE_OF_CONDUCT.md) e a [Política de Segurança](SECURITY.md).
